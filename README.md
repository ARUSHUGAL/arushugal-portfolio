# Portfolio (v1)

My first portfolio site — a static page built with plain HTML, CSS, and JavaScript, served from GitHub Pages.

**Live:** https://arushugal.github.io/arushugal-portfolio/

## Stack

- `index.html` — single-page layout
- `style.css` — hand-written CSS, no framework
- `script.js` — scroll interactions and section transitions

## Run locally

No build step. Open `index.html` directly, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

This is the older version. The current site lives in [portfolio](https://github.com/ARUSHUGAL/portfolio) — React + Vite with a TypeScript build.
